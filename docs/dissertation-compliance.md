# Соответствие веб-требованиям диссертации

Источник — текст задания владельца. Оригинальный «Требования к ПО для диссертации.docx» не приложен; итоговую сверку выполняет руководитель. Исходная версия c89860b: 44 теста, один URL, ThreadingHTTPServer. Текущая реализация и результаты — [testing.md](testing.md), [draft PR #2](https://github.com/mln2k/hydroflow/pull/2). Матрица описывает доступную техническую проверку, не удостоверяет внедрение или авторство студента.

| № | Требование | Статус | Реализация / доказательство / оставшееся действие |
| --- | --- | --- | --- |
| 1 | Python с Flask/Django | выполнено | Реальная Flask factory и 5 Blueprints, Waitress; [архитектура](architecture.md), hydroflow/server.py и web/; прежний handler удалён |
| 2 | Исходники, зависимости и версии | выполнено | requirements.txt с точными версиями, Docker/Compose, README Windows/macOS, source ZIP из Git; [комплект](delivery.md) |
| 3 | ≥50 содержательных коммитов студента в заданные периоды | не выполнено | [История](git-history.md) значительно короче; авторство и календарь не подтверждены, фиктивные коммиты не создавались |
| 4 | Бесплатный хостинг | частично | Render Free + Neon Free подготовлены; [инструкция](deployment.md). Публичного URL нет, нужны аккаунты и секреты владельца, затем проверка перезапуска/restore |
| 5 | Собственная реализация без CMS | выполнено | Собственные сервисы, SQL, формы и клиент; Flask/Waitress — инфраструктурные библиотеки, CMS/плагины предметной логики не применялись. Это не утверждение о собственноручном авторстве студента |
| 6 | Готовность к внедрению в бизнес-процесс | частично | [План испытаний](test-plan.md), функциональные проверки, инструкции обновления/копирования; реальная приёмка, нагрузка и эксплуатационный пилот не проведены |
| 7 | ≥2000 логических строк | не проверено | [Подсчёт](code-volume.md), scripts/code_metrics.py, перечень файлов. Порог не подтверждён; вспомогательные метрики не равны вузовской методике и не суммируются |
| 8 | ≥10 содержательных страниц | выполнено | [15 отдельных URL](routes.md), прямой запрос/reload/Back; API и браузерные проверки |
| 9 | Макет каждой страницы | выполнено | [15 HTML-макетов](mockups/index.html), отдельные содержательные примеры и адаптивный CSS; созданные при доработке, не скриншоты прошлых этапов |
| 10 | Форма обратной связи | выполнено | Автор/дата на сервере, категории, лимиты, идемпотентность, свои обращения, статусы и ответ ADMIN; FeedbackTests/browser_pages |
| 11 | ≥10 пунктов меню и breadcrumbs | выполнено | В проекте 12 содержательных ссылок участника / 14 ADMIN, рабочие breadcrumbs и активный пункт; [маршруты](routes.md) |
| 12 | SQL-СУБД | выполнено | SQLite и PostgreSQL 16; миграции v1/v2, внешние ключи, транзакции, CI обоих движков |
| 13 | ≥3 роли и демонстрационный доступ | выполнено | Сохранены 6 ролей; генератор создаёт отдельную БД и памятку случайных учебных паролей. Вход всеми шестью проверен; [комплект](delivery.md) |
| 14 | Панель администратора | выполнено | /admin/users и /admin/feedback; роль/блокировка/ответы; серверный запрет для остальных, защита ADMIN при конкурентном изменении |
| 15 | Личный кабинет | выполнено | /account, имя/email/роль, изменение имени, пароль с отзывом сеансов, проекты/назначения; самостоятельная смена роли/активности запрещена |
| 16 | Firefox, Chrome, Яндекс.Браузер, Edge | частично | Реальные Chrome/Edge и Firefox Playwright проверены отдельно; версии в testing.md. Яндекс.Браузер отсутствует и не проверен, [ручной сценарий](test-plan.md) подготовлен |
| 17 | ПК, ноутбук, смартфон | частично | Viewport 1920×1080 / 1366×768 / 390×844, мобильное меню, Firefox overflow исправлен; физические устройства не проверены |
| 18 | Содержательное предметное содержание | выполнено | Существующие проектные разделы, справка, новые формы; без инженерных расчётов, бухгалтерии, GitHub task sync и пустых страниц ради количества |

Код доработки создан с помощью ИИ. Технический комплект не доказывает авторство студента, соблюдение учебного календаря, экономический эффект или нормативное соответствие. Матрица не заявляет полного соответствия: открыты хостинг, часть браузерной/аппаратной проверки, объём кода, история и оригинал требований.
