# Страницы и макеты

Flask проверяет сессию и доступ к HTML до выдачи страницы. Клиент загружает данные через защищённый JSON API. `/` перенаправляет на `/projects`; `/projects/<id>` — на обзор. Неавторизованный запрос получает переход на `/login?next=...`; после входа открывается запрошенный раздел. Неизвестные разделы дают 404. Маршруты не являются копиями статических страниц: содержимое формируется соответствующими функциями `static/app.js` и `static/pages.js`.

| URL | Назначение и доступ | Макет |
| --- | --- | --- |
| `/login` | Вход, ошибки, возврат к запрошенному URL | [Вход](mockups/login.html) |
| `/projects` | Доступные проекты, создание для системных PM/ADMIN | [Проекты](mockups/projects.html) |
| `/projects/<id>/overview` | Прогресс и ближайшие задачи; участник/ADMIN | [Обзор](mockups/overview.html) |
| `/projects/<id>/requirements` | Требования, согласование, версии | [Требования](mockups/requirements.html) |
| `/projects/<id>/tasks` | Доска, таблица, статусы, исполнители, связи | [Задачи](mockups/tasks.html) |
| `/projects/<id>/stages` | Этапы, периоды и готовые связанные задачи | [Этапы](mockups/stages.html) |
| `/projects/<id>/documents` | Содержание, вложения и прежние версии | [Документы](mockups/documents.html) |
| `/projects/<id>/members` | Состав, проектные роли, управление для PM/ADMIN | [Команда](mockups/members.html) |
| `/projects/<id>/reports` | Прогресс, просрочки, влияние изменений; CSV/JSON/печать | [Отчёты](mockups/reports.html) |
| `/projects/<id>/activity` | Последние 100 действий в проекте | [История](mockups/activity.html) |
| `/account` | Свои данные, имя, пароль, проекты, назначенные задачи | [Кабинет](mockups/account.html) |
| `/feedback` | Свои обращения и ответы администратора | [Обратная связь](mockups/feedback.html) |
| `/help` | Порядок работы, роли, ошибки и границы системы | [Справка](mockups/help.html) |
| `/admin/users` | Пользователи, роли и блокировка; только ADMIN | [Администратор](mockups/admin-users.html) |
| `/admin/feedback` | Обработка всех обращений; только ADMIN | [Обращения](mockups/admin-feedback.html) |

В проекте меню содержит 12 содержательных ссылок для обычного участника: «Все проекты», восемь разделов, кабинет, обратная связь, справка; для ADMIN дополнительно две административные ссылки (14). Без выбранного проекта ссылки на его разделы не показываются. Выход и кнопки действий в этот подсчёт не входят. Breadcrumbs: «Проекты → название проекта → раздел», первые два элемента — рабочие ссылки. Активная ссылка помечена `aria-current=page`; поддержаны прямой URL, reload и Back.

[Карта макетов](mockups/index.html) содержит 15 отдельных HTML-макетов с общим CSS, содержательными примерами и адаптивным меню. Они созданы при этой доработке, не выдаются за предварительные материалы прошлых этапов и не являются скриншотами. Формы в них демонстрационные. Воспроизведение: `python scripts/make_mockups.py`. Макеты/генератор отделены от кода приложения при подсчёте объёма.

Проверки: `tests/test_dissertation.py::PagesTests` и `tests/browser_pages.cjs`. См. [результаты](testing.md) и [ручной чек-лист](test-plan.md).
