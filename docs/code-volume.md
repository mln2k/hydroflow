# Объём исходного кода

Снимок реализации на 23689df; документация и генерируемые макеты не входят в приложение. Повтор: `python scripts/code_metrics.py`. Полный список файлов и метрики: [code-metrics.json](code-metrics.json).

Это вспомогательная методика HF-metrics-1, а не утверждённая вузом методика логических строк. Физическая строка считается после исключения пустых, комментариев и строк только из управляющих символов. Python docstrings также исключаются. Многострочные литералы сохраняются как данные кода. Для JS используется лексическое удаление комментариев; вложенные template expressions и регулярные выражения ограничивают точность вспомогательной оценки. Число точек с запятой не равно числу операторов.

| Группа | Язык | Все физические строки | Учтённые физические | Вспомогательные единицы |
| --- | --- | ---: | ---: | ---: |
| application | Python | 1289 | 1082 | 850 |
| application | CSS | 8 | 5 | 496 |
| application | JavaScript | 174 | 161 | 115 |
| application | HTML | 27 | 27 | 31 |
| tests | JavaScript | 371 | 343 | 267 |
| tests | Python | 827 | 733 | 755 |
| tools | Python | 199 | 161 | 125 |

Единицы: Python — AST statements без docstrings, включая вложенные; CSS — декларации свойств; HTML — открывающие элементы; JavaScript — разделители `;` вне строк, только ориентир. Эти единицы разных языков **не суммируются** как логические строки. Разметка внутри JS-шаблонов отдельно не прибавляется, чтобы не считать один код дважды.

В application входят только hydroflow/, static/ и templates/. Tests и scripts вынесены в отдельные группы. Исключены зависимости, venv, данные, отчёты, картинки, сторонние библиотеки, HTML-макеты и их CSS. Старый static/index.html удалён как неиспользуемая точка входа.

**Порог 2000 логических строк не подтверждён.** Даже вспомогательные метрики не дают основания объявить его выполненным. Нужны утверждённая руководителем методика и её применение, либо обоснованная дальнейшая функциональная работа в границах проекта. Переносами, дублированием и макетами объём не увеличивался.
