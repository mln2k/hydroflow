## Уточнения проектных решений

Эти решения приняты при реализации, поскольку практика не задаёт их однозначно:

- Системная роль определяет право создавать проекты и администрировать пользователей. Для работы внутри проекта используется роль участника; ADMIN имеет доступ ко всем проектам.
- Создатель проекта становится его руководителем. В этой версии смена владельца проекта не предусмотрена; другие участники могут получить роль PM.
- PM управляет составом команды и утверждает требования. ANALYST редактирует требования; правка согласованного или отклонённого требования возвращает его в черновик.
- DEV и QA создают задачи своего направления и автоматически назначаются исполнителями. В существующей задаче они меняют только статус и только при наличии назначения. Руководитель, администратор и аналитик редактируют задачи целиком; назначает исполнителей PM/ADMIN.
- VIEWER читает проект, команду, историю, документы и отчёты; изменения и комментарии запрещены.
- Удаление требований, задач, документов и этапов доступно только ADMIN. Связанные с задачами требования и этапы нельзя удалить до снятия связей. Закрытие проекта выполняется сменой статуса; данные сохраняются.
- Комментарии в текущей версии добавляются и читаются. Их редактирование и удаление через интерфейс не предусмотрены.
- Статусы и приоритеты реализованы фиксированными значениями, а не редактируемыми справочниками. В дополнение к модели практики добавлены этапы, сессии, журнал и версии документов. Имена отдельных полей и таблиц отличаются от SQL-примера практики.
- Оценка влияния изменений показывает связи и предупреждает о завершённых задачах. Система не определяет автоматически, требуется ли доработка; решение принимает руководитель.
- Исходные утверждения об экономической эффективности не проверялись. Производственные данные не использовались.

## Исключённые функции

Расчёты прочности и гидравлики, BIM/ERP, бухгалтерия, снабжение стройки и мобильное приложение исключены разделом Scope OUT самой практики. Автоматическая синхронизация задач приложения с GitHub также не входит в требования; GitHub используется для исходного кода.
